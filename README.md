# SpringBoot HU's Eventify

Este repositorio reúne mi progreso de desarrollo con **Java y Spring Boot**. Su objetivo es conservar, de forma ordenada, la evolución del proyecto **Eventify** (una API REST para la gestión de eventos y lugares) a través del cumplimiento de Historias de Usuario (HUs).

Cada carpeta representa una semana de trabajo y contiene el proyecto Spring Boot con los avances arquitectónicos, de lógica de negocio y de persistencia abordados en esa etapa.

## Objetivos

- Fortalecer fundamentos de Java aplicados al desarrollo backend.
- Crear y escalar una API REST utilizando Spring Boot.
- Implementar una arquitectura en capas limpia (Controladores, Servicios, Repositorios, Modelos).
- Practicar persistencia de datos con Spring Data JPA y bases de datos relacionales (H2).
- Aplicar validaciones, manejo de excepciones personalizadas y pruebas automatizadas.
- Adoptar buenas prácticas de diseño, organización de código y testing.

## Tecnologías

* Java
* Spring Boot
* Maven
